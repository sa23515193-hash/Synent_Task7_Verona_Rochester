# Synent Task 7 — Stylo Gujrat Advanced Multi-Page Website

A polished responsive multi-page footwear-store website concept created for the **Synent Technologies Web Development Internship — Task 7**.

## Pages
- `index.html` — Home / hero / featured products
- `about.html` — brand story and timeline
- `services.html` — product collection with category filters
- `contact.html` — Gujrat store information + working front-end enquiry interaction

## Features
- Premium green + orange + blue + black visual system
- Responsive navigation with mobile hamburger menu
- Consistent UI across all four pages
- Product cards using current Stylo product imagery hosted on the official Stylo domain
- Direct links to official Stylo product listings
- Collection category filtering
- Contact form demo with success state
- Google Maps directions link
- No backend, npm or build step required

## Run locally
1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge.
3. Internet access is recommended because product images load from Stylo's official CDN and product buttons open the official website.

## Data / attribution note
The Gujrat store address and phone details were supplied for this internship project. Product names, product links, imagery URLs, and brand information were checked against Stylo's official website while preparing this version. This is a student portfolio/internship concept and is **not an official Stylo website**.
